# Registro de cambios

Una entrada por versión publicada, la más reciente arriba. La completa el agente en cada `release/` (skill `cerrar-release`) y en cada `hotfix/` (skill `implementar-rama`).

Formato de cada entrada:

```
## vX.Y.Z — AAAA-MM-DD

Hito: <nombre del hito en docs/contexto/roadmap.md, o «hotfix»>

- Casos de uso: CU-xx <título>, …
- Decisiones nuevas: D-xx <título>, …
- Correcciones: <hotfixes o bugfixes relevantes>, …
```
